# Sandbox contract v0.1

This initial vertical slice implements spot limit/market orders, GTC/IOC/FOK/post-only admission, exact balances, reservations, atomic settlement, fees, transfers and principal-only flexible Earn subscriptions. It is a prototype of the saved graph, not completion of N26/N49/N53/N64.

All amounts are positive decimal strings with at most eight places; no exponent or binary floating point. BTC/ETH/SOL trade against synthetic USDT. Prices use 0.01 ticks; quantities use instrument-specific steps. Quote notional must be exactly representable at eight places. Fees are 0.1% of each fill's quote amount, rounded upward to one quote atom, on both sides. Buyer reservations include a conservative per-lot rounding bound. FIFO is sequence order at the best executable maker price. Self-trades are excluded. Market orders are IOC and limited by an explicit protection price. FOK requires enough other-account executable quantity before reservation.

A single MySQL transaction serializes commands through a lock row and atomically updates orders, holds, fills, balanced postings, idempotency records and outbox. This deliberately bounded sandbox design has no separate matching-process/failover claim. Ledger buckets are available and held; user balances may not become negative. System faucet and fee accounts are explicit counterparties. Every posting group sums to zero per asset. Repeated command IDs return the original result; changed payloads conflict. Retrying uncertain execution must retain the command ID. Cancelled residual holds return only after prior fills are settled in the same transaction boundary.

Earn in this slice moves principal to a separate product wallet and supports redemption. It advertises no yield and has no accrual or staking receipt implementation. Authentication is password/session based, without passkeys, MFA, account recovery or production KYC. No external deposits, withdrawals or real money. All unimplemented graph capabilities must remain visible as planned, not cosmetic functional controls.
